# Audit Findings Register

## Project Overview

This folder contains an illustrative audit findings register for the fictional BalticTrust Bank cybersecurity GRC assessment.

## Objectives

- Document identified control weaknesses and observations.
- Record criteria, root causes, and risk ratings.
- Assign corrective actions, owners, and target dates.
- Track remediation status and supporting closure evidence.
- Support management oversight and continuous improvement.

## Workbook

- `Audit-Findings-Register.xlsx` — detailed findings register and summary dashboard.

## Disclaimer

BalticTrust Bank is fictional. The findings are illustrative portfolio examples, not verified audit results. This workbook is not a formal audit, legal opinion, or proof of compliance. Findings must be validated against objective evidence before being reported as actual issues.
