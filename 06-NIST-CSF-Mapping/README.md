# NIST Cybersecurity Framework Mapping

## Project Overview

This folder contains a cybersecurity control mapping for the fictional BalticTrust Bank GRC and DORA assessment, using the NIST Cybersecurity Framework (CSF) 2.0.

## Objectives

- Map selected internal security controls to relevant NIST CSF 2.0 outcomes.
- Identify cybersecurity strengths and gaps.
- Record recommended improvement actions.
- Support risk management and cybersecurity governance.

## NIST CSF 2.0 Functions

The framework organizes cybersecurity outcomes into six functions:

1. **Govern** — Establish cybersecurity strategy, responsibilities, and oversight.
2. **Identify** — Understand assets, business context, and cybersecurity risks.
3. **Protect** — Implement safeguards to reduce cybersecurity risks.
4. **Detect** — Identify potential cybersecurity events.
5. **Respond** — Manage and contain cybersecurity incidents.
6. **Recover** — Restore services and improve resilience after incidents.

## Planned Assessment Method

1. Review the bank's asset inventory, risk register, and security control catalogue.
2. Map applicable controls to relevant NIST CSF 2.0 categories and outcomes.
3. Record implementation status and supporting evidence.
4. Identify gaps and recommend remediation actions.
5. Review the results alongside the ISO 27001 and DORA assessments.

## Scope and Disclaimer

BalticTrust Bank is fictional and created for educational portfolio purposes. This mapping is an illustrative assessment, not a formal audit or compliance certification. NIST CSF 2.0 outcomes must be selected and evaluated according to the organization's scope, risk profile, and evidence.
