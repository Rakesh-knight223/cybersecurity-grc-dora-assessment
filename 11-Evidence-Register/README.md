# Evidence Register

## Project Overview

This folder contains an evidence register for the fictional BalticTrust Bank cybersecurity GRC assessment.

## Objectives

- Maintain a traceable index of supporting evidence.
- Link evidence to risks, controls, audit findings, and remediation actions.
- Record evidence owners, sources, versions, sensitivity, and review status.
- Support assessment reviews and remediation closure decisions.

## Workbook

- `Evidence-Register.xlsx` — evidence metadata, review tracking, and summary dashboard.

## Evidence Handling

Use synthetic or sanitized examples in this public portfolio. Never publish credentials, access tokens, personal data, customer records, confidential contracts, or sensitive system details. Placeholder paths beginning with `SIMULATED/` are examples and do not represent existing files.

## Disclaimer

BalticTrust Bank is fictional. Register entries are illustrative placeholders and do not prove that controls operate or that compliance has been achieved.
