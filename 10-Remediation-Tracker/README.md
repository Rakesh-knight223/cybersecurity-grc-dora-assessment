# Remediation Tracker

## Project Overview

This folder contains a remediation tracker for the fictional BalticTrust Bank cybersecurity GRC assessment.

## Objectives

- Link corrective actions to audit findings and identified gaps.
- Assign accountable owners and target dates.
- Track priorities, progress, blockers, and overdue actions.
- Record evidence supporting remediation.
- Require review before an action is marked closed.

## Workbook

- `Remediation-Tracker.xlsx` — remediation action register and summary dashboard.

## Workflow

Identify finding → define corrective action → assign owner and deadline → collect evidence → validate closure → update status.

## Disclaimer

BalticTrust Bank is fictional. The actions and dates are illustrative portfolio examples, not verified remediation activities or evidence of actual compliance.
