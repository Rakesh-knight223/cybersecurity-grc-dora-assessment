# Cybersecurity GRC & DORA Compliance Assessment

## Overview

This project presents a simulated Cybersecurity Governance, Risk and Compliance (GRC) assessment for a fictional European financial institution, **BalticTrust Bank**.

The project demonstrates how cybersecurity risks can be identified, assessed, controlled, monitored and remediated within a financial-sector environment.

The assessment incorporates established cybersecurity and regulatory frameworks, including:

- ISO/IEC 27001
- NIST Cybersecurity Framework (NIST CSF)
- Digital Operational Resilience Act (DORA)

> **Disclaimer:** BalticTrust Bank is a fictional organization created for educational and portfolio purposes. No real organization, system, customer data or security evidence is represented in this project.

---

## Project Objectives

The objectives of this project are to:

- Develop an IT and cybersecurity asset inventory
- Identify and assess cybersecurity risks
- Develop a cybersecurity control catalogue
- Map controls to ISO/IEC 27001
- Map cybersecurity activities to NIST CSF
- Assess alignment with DORA requirements
- Identify compliance and control gaps
- Document cybersecurity audit findings
- Develop remediation plans
- Maintain an evidence register
- Assess ICT third-party risks
- Develop incident-management and business-continuity processes
- Create a management-level cybersecurity risk dashboard

## Frameworks & Regulations

### ISO/IEC 27001

Used to assess the organization's information security management controls and identify areas for improvement.

### NIST Cybersecurity Framework

Used to structure cybersecurity activities across:

1. Identify
2. Protect
3. Detect
4. Respond
5. Recover

### DORA

The Digital Operational Resilience Act is used to assess ICT risk management and digital operational resilience within the fictional financial institution.
