# Final Cybersecurity GRC Assessment Report

## Overview
This folder contains the consolidated GRC Assessment Report for BalticTrust Bank, a fictional financial institution used for a cybersecurity GRC portfolio project.

The report summarizes the assessment approach, illustrative risk themes, governance responsibilities, remediation recommendations, monitoring activities, and supporting portfolio artifacts.

## Report
**File:** `BalticTrust-GRC-Assessment-Report.docx`

## Report Contents
- Executive summary
- Assessment objectives and scope
- Assessment methodology
- Illustrative cybersecurity and ICT third-party risks
- Governance and accountability
- Remediation and monitoring
- Management dashboard and reporting
- Assessment limitations and recommended next steps
- Portfolio artifact index and glossary

## Purpose
This report demonstrates how cybersecurity GRC activities can be organized and communicated in a financial-services context. It is intended for portfolio and learning purposes.

## Disclaimer
BalticTrust Bank, the sample risks, supplier information, findings, and metrics are fictional. This report is not an independent audit, certification, legal opinion, or evidence of DORA compliance. All examples require validation before any real-world use.
